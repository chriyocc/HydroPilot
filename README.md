# HydroPilot

HydroPilot is a monorepo for a hydroponic monitoring and control system built around three codebases:

- a Flutter mobile app
- ESP32 firmware
- a lightweight Node.js backend

## Repository Layout

```text
HydroPilot/
  app/                  # Flutter mobile application
  backend/              # Express backend service
  firmware/
    esp32/              # ESP32 firmware
  docs/                 # shared docs, API documentation, plans
  scripts/              # repo helper scripts
```
