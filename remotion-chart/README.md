# Animated Bar Chart

A small Remotion composition with five animated bars.

```powershell
pnpm install
pnpm run studio
```

Render the video:

```powershell
pnpm run render
```

Render a quick still preview:

```powershell
pnpm run still
```

If `node` is not available on your PowerShell PATH in Codex, use:

```powershell
.\start-studio.ps1
```
